## How I Build

- **AI-native engineering** — use agents as engineering tools, with explicit boundaries, review, and verification.
- **Local-first where it helps** — keep control of data, models, and operational workflows.
- **Production-minded architecture** — design for security, observability, recovery, and maintainability.
- **Evidence over assumptions** — tests, static analysis, security review, and reproducible checks.
- **Automation with guardrails** — idempotent workflows, least privilege, approval gates, and clear failure modes.
